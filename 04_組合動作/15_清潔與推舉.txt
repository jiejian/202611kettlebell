# 15 清潔與推舉（Clean and Press）

## 清潔與推舉（Clean and Press）

### 1. 清潔與推舉是什麼

**中文**：清潔與推舉（Clean and Press）是「上搏 → 肩推」的連續動作。
這是將壺鈴從地面（或擺盪位置）收到肩前，再從肩前推到過頭。
這個動作結合了上搏的力量傳遞與肩推的控制，適合進階者訓練肩部與核心。

**English**：Clean and Press is the continuous movement "clean → press."
It moves the bell from the ground (or swing position) to the shoulder, then from the shoulder overhead.
This movement combines the power transfer of the clean with the control of the press, suitable for intermediate trainees to train shoulders and core.

### 2. 清潔與推舉的標準流程

1. 站立，壺鈴置於雙腳之間。
2. 髖部後推，擺盪，執行上搏。
3. 壺鈴收到肩前（rack position）。
4. 核心繃緊，脊柱中立。
5. 爆發上升，手臂伸直，過頭。
6. 緩慢放下，回到肩前。
7. 重新執行上搏。
8. 連續完成。

**English**：
1. Stand, bell between the feet.
2. Hips push back, swing, perform a clean.
3. Bell at the rack position (shoulder).
4. Core braced, spine neutral.
5. Explosively rise, arm extended overhead.
6. Slowly lower, return to shoulder.
7. Repeat the clean.
8. Repeat.

### 3. 清潔與推舉的要點

| 要點 | 說明 |
|------|------|
| 清潔品質 | 上搏必須穩定，肘部收納 |
| 肩關節穩定 | 不要撞到肘部 |
| 核心繃緊 | 保護脊椎 |
| 呼吸 | 清潔時吸氣，推舉時呼氣 |
| 連動性 | 上搏與推舉要連貫 |

**English**：| Point | Description |
|-------|-------------|
| Clean quality | Clean must be stable, elbows tucked |
| Shoulder stability | Don't hit elbows |
| Core braced | Protect spine |
| Breathing | Inhale on clean, exhale on press |
| Continuity | Clean and press connected |

### 4. 常見錯誤

| 錯誤 | 修正 |
|------|------|
| 清潔失穩 | 練習上搏單獨 |
| 推舉時脊柱彎曲 | 核心繃緊 |
| 肩膀撞到 | 軌道調整，肘部外展 |
| 呼吸停頓 | 保持呼吸 |

**English**：| Mistake | Correction |
|---------|-----------|
| Clean unstable | Practice clean alone |
| Spine bends on press | Core braced |
| Shoulder hitting | Adjust trajectory, elbow abduction |
| Breath-holding | Breathe continuously |

## 2. 理論（Theory）

### 2.1 清潔與推舉的力量傳遞

**中文**：清潔與推舉是「上搏 → 推舉」的力量傳遞：
- 上搏將壺鈴從地面傳遞到肩前。
- 推舉將壺鈴從肩前傳遞到過頭。
- 這需要核心穩定、手臂控制與肩關節穩定。

**English**：Clean and Press is the power transfer "clean → press":
- Clean transfers the bell from ground to shoulder.
- Press transfers the bell from shoulder to overhead.
- This requires core stability, arm control, and shoulder stability.

### 2.2 肌群參與

**中文**：
- 主動肌：三角肌（前、側）、肱三頭肌、斜方肌（中段）、核心肌群。
- 穩定肌：竿樣肌、腹橫肌、腹斜肌。
- 輔助肌：胸肌、肱二頭肌。

**English**：
- Prime movers: deltoids (anterior, lateral), triceps, middle trapezius, core.
- Stabilizers: erector spinae, transversus abdominis, obliques.
- Assistants: chest, biceps.

### 2.3 公式

- 推舉的輸出功：\(W = m \times g \times h\)，質量乘以重力乘以高度。
- 肩部的力矩：\(τ = F \times d\)。
- 核心的張力：\(σ = \frac{F}{A}\)。

**English**：
- Press output work: \(W = m \times g \times h\).
- Shoulder torque: \(τ = F \times d\).
- Core tension: \(σ = \frac{F}{A}\).

## 3. 實踐（Practice）

### 3.1 階段練習

**中文**：零基礎者建議分階段：

| 階段 | 內容 | 目標 |
|------|------|------|
| 1 | 上搏 + 肩推 | 連動練習 |
| 2 | 8–12 kg 清潔與推舉 | 掌握連動 |
| 3 | 12–16 kg | 漸進 |
| 4 | 單手清潔與推舉 | 精細控制 |

**English**：| Stage | Content | Goal |
|-------|---------|------|
| 1 | Clean + Press | Connected practice |
| 2 | 8–12 kg clean & press | Master connection |
| 3 | 12–16 kg | Progression |
| 4 | Single-arm clean & press | Fine control |

### 3.2 清潔與推舉流程

1. 站立，壺鈴置於雙腳之間。
2. 髖部後推。
3. 髖部爆發，擺盪。
4. 執行上搏，壺鈴收到肩前。
5. 核心繃緊。
6. 推舉上升，過頭。
7. 緩慢放下。
8. 連續完成。

**English**：
1. Stand, bell between the feet.
2. Hips push back.
3. Hips explode, swing.
4. Clean, bell at shoulder.
5. Core braced.
6. Press overhead.
7. Slowly lower.
8. Repeat.

### 3.3 呼吸與穩定

- 清潔時：吸氣。
- 推舉時：呼氣。
- 核心繃緊，穩定。

**English**：
- On clean: inhale.
- On press: exhale.
- Core braced, stable.

## 4. 驗證（Verification）

### 4.1 任務（Tasks）

1. 說出清潔與推舉的兩個差異。
2. 說出清潔與推舉的主動肌與穩定肌。
3. 完成 3 組 × 8 次「無重清潔與推舉」。
4. 描述上搏與推舉的連動感。

### 4.2 自我檢查（Self-check）

- 站立姿勢正確，雙腳跟穩定。
- 清潔穩定，肘部收納。
- 推舉時核心繃緊。
- 呼吸連續。

### 4.3 能力測試（Competency test）

- 能以 8–16 kg 壺鈴完成「雙手清潔與推舉」，3 組 × 8–10 次。
- 姿勢無明顯崩潰。
- 能用自己的話說出清潔與推舉的要點。
