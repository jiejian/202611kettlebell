1. 套件概述

概念套件概述

中文

這是一套「壺鈴健身」教材，針對「完全零基礎」的讀者，目標是建立一般健身與體能。 套件包括 28 個章節，涵蓋基礎概念、動作學習、組合動作、訓練設計、安全與測試。 每個章節均提供文字檔（.txt）與 HTML 檔。

English

This is a set of "kettlebell fitness" teaching materials, designed for "completely beginner" readers, with the goal of building general fitness and conditioning. The set includes 28 chapters covering basic concepts, movement learning, combined movements, training design, safety, and testing. Each chapter provides a text file (.txt) and an HTML file.

概念風格方向

中文

本套件以俄式（Girevoy / 流暢風格）為主，硬式（Hardstyle / 爆發力風格）為輔： - 俄式：強調連續、穩定、耐力、呼吸連續。 - 硬式：強調髖伸展爆發、核心剛性、發力節奏。 - 兩者在同一動作中皆有描述，讀者可依自身目標選擇重點。

English

This set is primarily Russian (Girevoy / Fluid Style), with Hardstyle (Explosive Power Style) as secondary: - Russian: emphasizes continuity, stability, endurance, continuous breathing. - Hardstyle: emphasizes explosive hip extension, core rigidity, power rhythm. - Both are described in the same movement; readers may emphasize according to their goals.

3. 格式規範

概念格式規範

中文

文字檔（.txt）： - UTF-8 編碼。 - 純文字，方便查閱、複製與版本管理。 HTML 檔（.html）： - 支援雙語：中文在前，英文在後。 - 支援數學公式（KaTeX / LaTeX）：\(E=mc^2\)。 - 章節跳轉連結：本頁目錄。 - 章節導航：上一節／下一節。 - 圖示與影片連結。 - 主題標籤：理論（Theory）、實踐（Practice）、驗證（Verification）。

English

Text files (.txt): - UTF-8 encoding. - Plain text, convenient for viewing, copying, and version control. HTML files (.html): - Bilingual support: Chinese first, English second. - Math formulas support (KaTeX/LaTeX): \(E=mc^2\). - Chapter navigation: previous/next section. - Jump links: Table of contents. - Diagrams and video links. - Topic labels: Theory, Practice, Verification.

概念每章固定結構

中文

每個章節均包含以下結構： 1. 概念與說明（Concept & Description） 2. 理論（Theory） 3. 實踐（Practice） 4. 驗證（Verification）— 任務、共自我檢查、能力測試 5. 動作參考（Action References）— 圖示、影片、補充資源 6. 練習建議（Training Suggestions） 7. 常見問題（FAQ）— 如有

English

Each chapter contains the following structure: 1. Concept & Description 2. Theory 3. Practice 4. Verification — Tasks, Self-check, Competency test 5. Action References — Diagrams, Video, Supplementary Resources 6. Training Suggestions 7. FAQ — if applicable

4. 如何使用

概念如何使用

中文

1. 從「00 索引」開始，閱讀「說明書」與「目錄」。 2. 依照「依賴關係」的順序進行，先學習基礎概念再學動作。 3. 每一個章節，先閱讀「理論」，再練習「實踐」，最後完成「驗證」。 4. 在 HTML 檔中使用目錄與章節跳轉快速瀏覽。 5. 每次訓練前先熱身，後放鬆。 6. 若有疼痛或不適，立即停機並尋求協助。

English

1. Start from "00 Index", read "說明書" and "目錄". 2. Follow the "依賴關係" order; learn basic concepts before movements. 3. For each chapter, read "Theory" first, then practice "Practice", then complete "Verification". 4. Use the HTML files' table of contents and chapter jump links for quick browsing. 5. Warm up before each session and cool down after. 6. Stop immediately if pain or discomfort occurs, and seek assistance.
